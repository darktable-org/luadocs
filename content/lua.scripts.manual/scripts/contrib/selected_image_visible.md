## Name

selected_image_visible.lua - make the selected image visible in lighttable

## Description

selected_image_visible adds a shortcut to make the currently
selected image or the first image of a selection visible in lighttable

## Usage

* start the script from script_manager or require it in the user luarc file
* assign a keystroke to the shortcut in preferences->shortcuts

## Additional Software Required

None
