## Name

harmonic_armature_guide.lua - Harmonic Armature (also known as 14 line armature)

## Description

harmonic_armature_guide adds another guide to the darktable guides.

## Usage

* start the script from script_manager or require it in the user luarc file
* when using guides, select "harmonic armature" as guide
