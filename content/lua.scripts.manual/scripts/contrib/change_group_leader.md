## Name

change_group_leader.lua - automatically change the leader of raw+jpg paired image groups

## Description

change_group_leader adds a module to lighttable that changes the group leader of raw+jpg 
image groups to the selected image type, either raw or jpg.  change_group_leader can also 
handle raw+non-raw groups and change the group leader to the non-raw image.

## Usage

* start change_group_leader from script_manager or require it in the user luarc file
* in lighttable mode, select the image groups you wish to process, select whether you want to set the leader to "jpg" or "raw", and click "Execute"
