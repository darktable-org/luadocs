## Name

toggle_group_view.lua - toggle only group visible in lighttable

## Description

toggle_group_view provides an action button and a shortcut to "separate" a group from
the lighttable display and limit the display to just the group.

To display just the group in lighttable select (or hover over) a member of a group
and use the shortcut or the action button to toggle the view to just the group.  Using
the button or shortcut again will return to the full lighttable view.

## Usage

* start the script from script_manager or require it in the user luarc file
* assign a keystroke to the shortcut in preferences->shortcut
